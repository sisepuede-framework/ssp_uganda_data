# How well the surrogate predicts each variable

This is the performance of the XGBoost surrogate on the runs it never saw during training, for every one of its 258 targets. A target is one output of the model in one year: 43 outputs (emissions by sector, benefits, costs and GDP) × 6 years. We trained it on 79,670 of the SISEPUEDE runs and kept 19,918 apart to test it. This is the model we retrained on 2026-10-16, without the outlier filter, and it's the engine the agent used in the 290 conversations.

Run `2026-05-30t21;35;56.244639` · model `xgb_pipeline_sector_independent_2026-05-30t21;35;56.244639.pkl`.

## How to read it

For each target we report four numbers, and each one answers a different question:

- **R²**: how much of the difference between runs the surrogate reproduces. 1 means it gets all of it, 0 means it does no better than always giving the average, and below 0 means it does worse than that.
- **MAE**: how far the prediction is from the real value on average, in the target's own units. **RMSE** is the same idea, but big errors count more.
- **SMAPE**: that same error as a percentage of the value, so we can compare targets with different units.
- **Spread**: how much the real value changes from one run to another (standard deviation over the test runs). When the spread is almost zero, R² stops being meaningful, so there we read MAE instead. *no var.* means a spread below 10⁻⁶.
- Units: Emissions: Mt CO₂e; Benefits: billion USD; Costs: billion USD; GDP: billion international $ (PPP, constant prices).

## Why 2025 is reported separately

The story is simple: in 2025 there is almost nothing to predict.

R² compares the surrogate's error with how much the target changes between runs, R² = 1 − (error ÷ variation between runs). The policies and uncertainties ramp in from the 2019 base, so by 2025 they have barely moved anything, and the runs look almost the same. In 33 of the 43 outputs the spread is below 10⁻⁶ (median 5.7e-14, against 0.51 in 2035–2070). When we divide by a number that is almost zero, R² explodes to huge negative values, as low as -6.2e+16, even though the error itself is tiny: median MAE 3.8e-09, and the largest is 0.0022.

So the surrogate is not failing in 2025. It predicts a value that hardly changes, and its errors are tiny. Among the few outputs that already move a little by 2025, some score well, like transport emissions (R² 1.00), and others don't, like technical costs (0.51) or deforestation (-0.32), but even there the spread is so small that the error is too. If we mixed 2025 into the averages, it would pull them down for a reason that has nothing to do with accuracy, so we keep it apart and list it in full below.
