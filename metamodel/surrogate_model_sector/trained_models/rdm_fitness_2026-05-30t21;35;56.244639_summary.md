## Not checked: thresholds relative to BAU in the same future

The tools' 'X% below BAU' test compares a policy with BAU in the same future. Every held-out run has its own future, so there is no true BAU to compare with. Checking it needs paired model runs: for a sample of futures, BAU and a few policies (for example 200 futures x 3 runs, about 30 hours of model time at about 3 minutes per run).
